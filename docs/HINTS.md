# Optional hints

Use these only when you want help. Start with one hint and return to the lab before reading further. The guided browser controls perform real requests; you never need to type a command.

## The opening clue

1. Compare the words in the guild conversation with the words in the sales slide.
2. Was the conversation meant for Gallantir's customers? What does the matching phrase establish, and what does it leave unexplained?
3. Record what you see before deciding how the phrase travelled.

## The training account

1. Open a record your account is allowed to see. A record is a small file of information held by CivicLens.
2. A record reference identifies which file you ask the server to open. Knowing a reference should not itself give you permission to read it.
3. The supplied slide has a reference. Compare it with the references in your account's list.
4. Use the numbered record field to ask for the reference you found. Read the actual response, then decide whether the account should have received it.

## Evidence and protection

1. Save the actual response that supports your finding. Explain what it shows in your own words.
2. Reading a file and sending new information into the platform are different actions. Fixing one does not automatically stop the other.
3. Ask Codex to guide the defence step. The source repair belongs to the blue agent; your decisions and observations belong to you.
4. A protective change needs a new test. Check both the forbidden action and an action that should still work.

The full solution is separate from this hint ladder. This is a guided learning exercise, so using a hint is part of the record of assistance rather than a failure.
