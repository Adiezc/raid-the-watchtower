# Sources and limits

The story, organisations, messages and records are invented. These references support the concepts taught by the lab. They are not evidence of a real surveillance incident or validation of this application.

## Record permissions

Knowing which record to request does not establish permission to read it. The server must check the caller's rights for the requested object. That is the distinction illustrated by the intentional flaw. [OWASP API1: Broken Object Level Authorization](https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/).

## Youth rights framing

The United Nations Convention on the Rights of the Child recognises freedom of association and peaceful assembly in Article 15 and addresses arbitrary or unlawful interference with privacy and correspondence in Article 16. These provide context for the fictional community's concerns. The lab does not assess a real organisation's legal compliance. [Convention text hosted by UNICEF](https://www.unicef.org/child-rights-convention/convention-text).

## Local server

Python provides the HTTP handler and threaded server used for the loopback training application. Its documentation says this server module is unsuitable for production use. The project is designed as a local educational exercise. [Python 3.9 HTTP server documentation](https://docs.python.org/3.9/library/http.server.html).

## AI assistance

The recorded exercise will show what this particular agent team actually did. It will not establish that autonomous agents replace professional security assessment. Development agents, participant observations and live red/blue tasks are reported separately.
