# NextVoice Nightwatch

The guild is named NextVoice Nightwatch, connecting its members to the fictional youth rights group. A three-flame lantern represents shared vigilance and young voices. The game world uses low-poly basalt, charcoal chat surfaces, iron fittings, worn bronze and bone type. The latest direction takes inspiration from World of Warcraft Classic, Molten Core and Blackrock Depths, using an original volcanic fortress scene and hand-painted textures. CivicLens retains a cold slate corporate identity and the defence view uses a real local terminal vocabulary.

Applied the [Frontend Design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), read into an ignored local review folder, and the Codex imagegen skill. The design review favoured a compact guild client and one current lead rather than a promotional landing page. Background, hints and saved evidence use optional drawers. The slide precedes notes, saved first thoughts precede record tools and a saved restricted response precedes the responder invitation. This progression is guidance, not a server security boundary.

## Artwork and icons

`web/nightwatch-hall.png` is original generated raster artwork produced with the built-in imagegen tool on 10 October 2026. It was copied into the project and visually inspected. No external image hosting or franchise artwork is required. The shallow banner crop is implemented in CSS. Lantern, prism and case-file icons are local SVG symbols; the three character portraits are local SVG artwork.
